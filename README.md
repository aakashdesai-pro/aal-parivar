# 🛕 આલ પરિવાર - દાન પોસ્ટર નિર્માતા

એક સરળ, આધુનિક અને ૧૦૦% ક્લાયન્ટ-સાઇડ (No-Backend) વેબ ટૂલ, જેના દ્વારા આલ પરિવાર મઢ (ભેચડા) માટે કોઈપણ દાતાના જન્મદિવસ, લગ્ન વર્ષગાંઠ કે અન્ય શુભ પ્રસંગે કરેલા દાનનું સુંદર પોસ્ટર બનાવી શકાય છે.

---

## 🌟 મુખ્ય વિશેષતાઓ (Key Features)

1. **૧૦૦% નો-બેકએન્ડ (Zero Backend & Offline Ready)**:
   - કોઈ સર્વર કે ડેટાબેઝની જરૂર નથી.
   - સીધું કોઈપણ બ્રાઉઝરમાં `index.html` ખોલીને વાપરી શકાય છે.
   - ઑફલાઇન પણ ૧૦૦% કામ કરે છે.

2. **પવિત્ર અને આકર્ષક ડિઝાઇન**:
   - ઉપર ગોલ્ડન-યલો પવિત્ર આભા અને મંડલા પેટર્ન.
   - મઢનો ફોટો અને સુશોભિત ફ્રેમ.
   - નીચે સુંદર મંદિર ગુમ્બજ આકાર (Temple Arch) સાથે ડીપ પીકોક/ટીલ બેકગ્રાઉન્ડ.
   - પ્રસંગ બેજ (દા.ત. *જન્મદિવસ નિમિત્તે*), દાતાનો ફોટો, દાતાનું નામ, રકમ અને તારીખ.

3. **દાતા ફોટો ક્રોપ અને એડજસ્ટમેન્ટ**:
   - મોબાઇલ કે કમ્પ્યુટરમાંથી ફોટો અપલોડ (Drag & Drop સપોર્ટ).
   - ઝૂમ (Zoom), ઉપર-નીચે (Pan Y) અને ડાબે-જમણે (Pan X) સ્લાઇડર્સ જેથી ફોટો બરાબર ફ્રેમમાં સેટ થઈ જાય.

4. **ઝડપી પસંદગી (Quick Presets)**:
   - પ્રસંગો: જન્મદિવસ, લગ્ન વર્ષગાંઠ, પુણ્યતિથિ, શુભ પ્રસંગ, મહા શિવરાત્રી, નવરાત્રી, અથવા પોતાનો કસ્ટમ પ્રસંગ.
   - દાન રકમ શોર્ટકટ્સ: ₹101, ₹251, ₹501, ₹1,100, ₹2,100, ₹5,100, ₹11,000, ₹21,000.
   - દાતાના નામમાં ઝડપી ઉપનામ ઉમેરો: `+ શ્રી`, `+ ભાઈ`, `+ બેન`, `+ સ્વ.`, `+ સપરિવાર`, `+ કુમાર`.
   - "આજની તારીખ (Today)" ઓટો-સેટ બટન.

5. **કસ્ટમાઇઝેશન માટે અલગ JSON ફાઈલ (Static Temple Config)**:
   - મંદિરનું નામ, સૂત્ર, ગામનું નામ, અને આભાર સંદેશ હવે [`config.json`](config.json) ફાઈલમાં સેવ છે.
   - તમારે માત્ર [`config.json`](config.json) ફાઈલમાં ફેરફાર કરવાનો રહે છે, જેથી દર વખતે ફોર્મ ભરતી વખતે આ વિગતો લખવાની જરૂર રહેતી નથી.
   - બ્રાઉઝરમાં નીચે આપેલા **"📁 config.json બદલો"** બટન પર ક્લિક કરીને પણ નવી JSON ફાઈલ અપલોડ કરી શકાય છે.

6. **ડાઉનલોડ અને શેરિંગ (Export & Share)**:
   - **📥 HD PNG ડાઉનલોડ**: ૧૦૮૦ x ૧૭૬૦ રિઝોલ્યુશન (વોટ્સએપ સ્ટેટસ / ઇન્સ્ટાગ્રામ સ્ટોરી માટે ક્રિસ્ટલ ક્લિયર).
   - **📲 વોટ્સએપ પર શેર**: એક જ ક્લિકમાં દાતા અને દાનની વિગત સાથે વોટ્સએપ પર શેર.
   - **📋 ક્લિપબોર્ડ કોપી**: ઈમેજ કોપી કરી સીધી વોટ્સએપ વેબમાં `Ctrl + V` થી પેસ્ટ કરી શકાય.

## 🚀 કેવી રીતે વાપરવું (How to Run)

### પદ્ધતિ ૧: સીધું ફાઈલ ખોલો (Direct File Open)
`index.html` ફાઈલ પર ડબલ ક્લિક કરી Chrome, Edge, Safari કે Firefox માં ઓપન કરો.

### પદ્ધતિ ૨: લોકલ સર્વર (Local Server - Optional)
જો તમે ટર્મિનલમાં હોવ:
```bash
python3 -m http.server 8000
```
અને બ્રાઉઝરમાં `http://localhost:8000` ઓપન કરો.

### પદ્ધતિ ૩: ઓનલાઇન ફ્રી હોસ્ટિંગ (Free Online Hosting)
આ પ્રોજેક્ટ સંપૂર્ણપણે static ફાઈલો (`index.html`, `style.css`, `canvas-renderer.js`, `app.js`, `assets.js`) ધરાવે છે, તેથી તેને નીચે મુજબ ૧ મિનિટમાં ફ્રીમાં લાઈવ કરી શકાય છે:
- **GitHub Pages**: આ રિપોઝીટરીને GitHub પર પુશ કરી Settings -> Pages માં `main` બ્રાન્ચ સિલેક્ટ કરો.
- **Vercel / Netlify**: આ ફોલ્ડર ડ્રેગ એન્ડ ડ્રોપ કરીને લિંક બનાવી આખા મંદિર ગ્રૂપને વોટ્સએપમાં આપી શકો છો.
