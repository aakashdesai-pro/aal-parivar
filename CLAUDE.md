# CLAUDE.md - આલ પરિવાર (Aal Parivar - Bhechada)

## Critical Guidelines for Claude

### Language & Communication
- Respond to the user strictly in **Hinglish** (Roman script Hindi/English).
- Keep all UI labels, form fields, and poster outputs strictly in **Gujarati Script (ગુજરાતી લિપિ)**.

### Strict Project Rules
- **No Commercial / Marketing Copy**: Internal community tool only. Do not add marketing badges, promotional buzzwords, or counter tags.
- **Forbidden Term**: Never write or output **"નેસ મેનેજર"** anywhere. The brand is strictly **"આલ પરિવાર"**.
- **Minimalist Scope**: Only implement what is requested. Never add unasked placeholder tools or coming-soon cards.
- **Client-Side Only**: 100% vanilla web stack (HTML5 / CSS3 / Vanilla JS) without external frameworks or build tooling.

### Configuration
- `config.json` is the main configuration file.
- `config.js` is the offline fallback wrapper for browsers opening via `file:///`. Keep both files in sync.

### Visual Design
- **Theme**: Golden-Yellow aura top, Deep Peacock Teal bottom.
- **Layout**: Symmetrical temple arch curve (મંદિર ગુમ્બજ આકાર) with gold piping separating sections.
